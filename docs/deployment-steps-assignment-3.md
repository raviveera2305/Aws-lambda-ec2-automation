🚀 Assignment 3 — Monitor Unencrypted S3 Buckets Using AWS Lambda and Boto3

Overview

This document describes the deployment and validation of a serverless AWS security monitoring solution that detects S3 buckets without server-side encryption configuration. The solution uses AWS Lambda, Python Boto3, Amazon S3, AWS IAM, and Amazon CloudWatch Logs.

🎯 Objective

Automate the detection of S3 buckets that do not have server-side encryption configured.

•	Lists all accessible S3 buckets.

•	Checks the server-side encryption configuration of each bucket.

•	Identifies buckets without an encryption configuration.

•	Logs encrypted and unencrypted bucket status.

•	Reports the final security scan result through CloudWatch Logs.

☁️ AWS Services Used

•	Amazon S3

•	AWS Lambda

•	AWS IAM

•	Amazon CloudWatch

•	Python Boto3 SDK

The Lambda function was implemented using Python and the Boto3 SDK.

4.	Identifies buckets without encryption configuration.

5.	Logs the encryption status of each bucket.

6.	Reports the list of unencrypted buckets.

🔐 Security Considerations

The Lambda function operates in a read-only manner and does not modify S3 buckets or objects.

**AmazonS3ReadOnlyAccess** is used for S3 inspection, while:

**AWSLambdaBasicExecutionRole** is used for CloudWatch logging. For production environments, IAM permissions should follow the principle of least privilege and be restricted to the resources and API actions required by the monitoring solution.
